# Requirements

Bookself is intentionally light.

| Use Bookself to… | You need… |
|---|---|
| **Read** | A modern web browser |
| **Write on GitHub** | A browser + GitHub account |
| **Work locally** | Git + Python 3 |

**Supported:** macOS, Windows, and Linux.

There is no Node.js, npm, pip-package, Docker, database, or build-system requirement. The Reader and Publishing Desk are static browser software, and Bookself's local Python tools use the standard library.

GitHub CLI is optional. Shell scripts are optional convenience wrappers, not part of the core requirement.

> **Read with a browser. Author with a browser. Work locally with Git + Python. Install no application dependencies.**

For the compatibility policy and maintainer guidance, see [`docs/compatibility.md`](docs/compatibility.md).
