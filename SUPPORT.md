# Platform support

Bookself supports **macOS, Windows, and Linux**.

For most people, Bookself has no local requirements at all: open it in a browser and write on GitHub.

For local work, the supported baseline is:

- Git
- Python 3

No application dependency installation is required.

See [`REQUIREMENTS.md`](REQUIREMENTS.md) for the one-glance version and [`docs/compatibility.md`](docs/compatibility.md) for the compatibility policy.
