Use `Authors` for the editor or contributor line you want visible on the cover. `Author Links` can hold editor and contributor profiles; `Find elsewhere` can point to the publisher, bookstores, library catalogs, or other editions.

This starter keeps the collection in one manuscript file so a new anthology can begin without directory overhead. Split individual works into separate manuscript files later only when editorial review or navigation benefits from it.
