# Editions

These files describe target intent. They do not contain final printer coordinates or claim that an export passed a live platform check.

- `paperback-letter.json` — 8.5 × 11 paperback starting point.
- `kindle.json` — reflowable eBook starting point.

Copy or rename an edition file for a deliberate target, trim, binding, paper, or platform. Keep the canonical manuscript and production evidence shared; derive exports from them.
