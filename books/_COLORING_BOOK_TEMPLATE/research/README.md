# Research index

This is the canonical research entry point for the publication. Record source identity, stable links or identifiers, access dates for changing sources, how each source informed a scene or production decision, limitations, counterevidence, and any recheck needed before release.

For visual work, keep references, character-model decisions, and print research here or in the production artifacts they inform. Do not commit third-party source files merely because an agent could access them; preserve provenance and redistribution rights.
