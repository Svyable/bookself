Use this folder for an issue that Bookself hosts directly. Rename the folder to a lowercase hyphenated slug, replace the sample metadata, and write the issue in `manuscript/issue.md`.

`Author Links` is for profiles belonging to the people behind the publication. `Find elsewhere` is for legitimate places readers can find this issue or publication outside Bookself. Both fields accept ordinary Markdown links separated by a middle dot:

```md
| **Author Links**   | [Goodreads](https://www.goodreads.com/) · [Website](https://example.com/) |
| **Find elsewhere** | [Publisher](https://example.com/) · [WorldCat](https://search.worldcat.org/) |
```

Use real destination pages before publishing. Retailers, libraries, archives, publisher catalogs, and author-selected profile services can all be linked without making Bookself depend on them.
