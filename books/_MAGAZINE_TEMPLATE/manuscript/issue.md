# Your Magazine — Issue 1

Open with the piece that earns the cover. This can be an editor's note, a short introduction, or the first feature itself. Replace this scaffolding with the issue you actually want readers to encounter.

## Feature

Write the main feature here. Images can live in `../media/` and use ordinary Markdown image syntax.

## Dispatches

Shorter pieces can share the issue when they belong together. If an article grows into something that deserves its own revision history, move it into a separate manuscript file and add that file to the publication README in its own change.

## Contributors

Credit writers, editors, photographers, illustrators, researchers, and other contributors here. Link names to author-controlled profiles when useful, and keep retailer or library discovery links in the publication README so readers can find them from the cover.
