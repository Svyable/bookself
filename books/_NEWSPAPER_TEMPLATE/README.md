Use this folder for one newspaper edition hosted by Bookself. Rename the folder to a lowercase hyphenated slug, replace the sample metadata, and write the edition in `manuscript/edition.md`.

`Author Links` can point to the newsroom, editor, columnist, or contributor profiles. `Find elsewhere` can point readers to the newspaper's own site, an archive, a library catalog, a print subscription page, or another legitimate source:

```md
| **Author Links**   | [Newsroom](https://example.com/about) |
| **Find elsewhere** | [Official edition](https://example.com/edition) · [Library catalog](https://examplelibrary.org/item) |
```

Use real destination pages before publishing. Bookself stores these as ordinary links; the outside service remains responsible for availability, lending, purchasing, or archival access.
