This starter keeps the screenplay in plain text using Bookself's Fountain-compatible screenplay core. The source remains readable in Git and can travel through the same Desk → Shelf release workflow as a book.

Write scene headings as `INT.` / `EXT.` lines, character cues in uppercase, dialogue directly below the cue, and parentheticals in parentheses. Common conveniences such as forced scene headings (`.MONTAGE`), forced character cues (`@McCLANE`), forced action (`!`), transitions (`CUT TO:` or `> FADE OUT:`), centered text (`> THE END <`), writer-room sections (`# ACT ONE`), and explicit page breaks (`===`) are recognized.

Writer-room `#` sections are outline/navigation metadata and do not print. If an act heading should appear on the screenplay page, add a centered line such as `> ACT ONE <` as the sample script does.

In the Reader, open **Lines** (or press `r`) to choose a role, hide that character's dialogue, reveal lines by tap/click or keyboard, and move cue by cue. Rehearsal state stays in the actor's browser and never edits the manuscript.

See [Screenwriting with Bookself](../../docs/screenwriting.md) for collaboration, formatting, rehearsal, and current compatibility boundaries.
