# Back Matter

## Epilogue

You have reached the end of a book by following the same files you could have opened in Git.

That is the trick, if there is one. Bookself does not need a second manuscript hiding behind the Reader. This guide is a folder, a small history of changes, and a reading surface laid over the top. A real book can be larger and stranger without requiring a more mysterious foundation.

The Binder is where the next version can become messy. The Shelf is where a released version can stay still. Between them is a deliberate copy of a committed snapshot, not an invisible publishing machine.

Close this book and the source is still there. Change the source and Git can remember what it used to say. Release it and the public copy can stand on its own.

Put a book in the Binder.

## Acknowledgments

This guide exists so authors and agents can inspect the whole loop: files, Reader, private revision, verified release, and public recovery. It should remain small enough to understand without becoming a miniature documentation site.
