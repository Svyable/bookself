## This book is intentionally unfinished

**Making Bookself** is a public teaching specimen of a Binder-style working copy.
A real Bookself Binder should normally be private. This one is public on purpose
so authors, students, professors, maintainers, and AI agents can inspect the
process while it is happening.

- [Read the working proof](https://svyable.github.io/bookself/reader/#/b/making-bookself/)
- [Read the live review notes](REVIEW.md)
- [Join the public review thread](https://github.com/Svyable/bookself/issues/35)
- [Inspect its Git history](https://github.com/Svyable/bookself/commits/main/books/making-bookself)
- [Browse the released public Shelf](https://svyable.github.io/shelf/reader/)

The experiment is recursive: use Bookself to write a book about making books,
then use what hurts in that process to improve Bookself itself.
