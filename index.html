Git-native publishing infrastructure

Bookself

Bookself is the reusable structure beneath author-owned publishing. Work lives on a Desk. Deliberate releases live on a Shelf. Both use the same Reader, while Bookself supplies the templates, release tools, validation, and upgrades.

Open demo Shelf Set up Desk + Shelf Architecture Project README Reader component Publishing Desk component

Desk

Working manuscripts, drafts, research, revisions, and the next edition. Desk owns author content while it is in motion.

Shelf

Deliberately released snapshots. A Shelf is independently readable and never needs to fetch manuscript files back from Desk. Bookself's own embedded demo Shelf uses neutral platform specimens from this repository.

Shared upgrades

python3 scripts/sync-ui.py updates Reader and Publishing Desk behavior without replacing instance books, catalogs, or identity.

Release

python3 scripts/release-book.py prepares a verified committed Desk snapshot for Shelf. Publishing remains a deliberate event.

Bookself is not an author library. Platform specimen publications exist only to exercise and demonstrate software behavior. Working author manuscripts belong in Desk; released author editions belong in Shelf.
